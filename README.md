# Dell-Hackathon-Service-Recommendation-System

Description:
An intelligent, multi-factor recommendation system designed to deliver personalized service recommendations, enable proactive customer support, and improve customer conversion rates, satisfaction, and retention.

The system leverages multiple customer-centric factors, behavioral patterns, service preferences, and engagement signals to generate relevant recommendations and identify opportunities for proactive intervention.

Objective: Build a data-driven recommendation engine that enhances customer experience, drives service adoption, increases conversion rates, and fosters long-term customer loyalty.

Key capabilities include:

1) Personalized Recommendations: Recommends relevant services based on multiple customer attributes and behavioral factors.

2) Proactive Customer Support: Identifies customer needs and recommends timely support actions to improve the overall experience.

3) Conversion Rate Optimization: Suggests targeted measures and personalized offers to increase service adoption and conversion.

4) Customer Retention: Identifies opportunities to strengthen customer relationships and reduce churn.

5) Loyalty-Based Recommendations: Incorporates customer loyalty tiers, including Gold Membership, to provide exclusive recommendations, benefits, and personalized experiences.

6) Multi-Factor Decision Engine: Evaluates multiple parameters to generate intelligent, context-aware recommendations.


# Install guide

Clone repository git clone https://github.com/garg19priya/Dell-Hackathon-Service-Recommendation-System

Change Directory to the repo cd dell-hackathon-submission

Install requirements sudo pip3 install -r requirements.txt

Start Django Server after running migrations

python3 manage.py makemigrations
python3 manage.py migrate
python3 manage.py runserver
